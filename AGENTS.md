# Инструкции для работы с кодовой базой (Staff Status Tracker)

Этот документ содержит инструкции по настройке, структуре и основным принципам работы с данным проектом.

## 1. Обзор проекта

Это многопользовательское веб-приложение на PHP и MySQL для отслеживания ежедневного статуса сотрудников по отделам.

**Основные возможности:**
- **Две роли пользователей:** `admin` и `department`.
- **Администраторы** могут управлять отделами, пользователями и просматривать логи.
- **Пользователи отделов** могут вводить ежедневные данные о статусе своего отдела.
- **Все пользователи** могут просматривать сводную таблицу со статусами по всем отделам.

## 2. Настройка и установка

Для развертывания приложения выполните следующие шаги:

1.  **Настройте подключение к базе данных:**
    - Откройте файл `config.php`.
    - Измените значения `DB_HOST`, `DB_NAME`, `DB_USER` и `DB_PASSWORD` в соответствии с вашими настройками сервера MySQL.

2.  **Запустите скрипт установки:**
    - Откройте в браузере `http://<ваш-домен>/install.php`.
    - Этот скрипт автоматически создаст базу данных (если она не существует) и все необходимые таблицы (`departments`, `users`, `statuses`, `logs`).
    - Он также создаст учетную запись администратора по умолчанию.

3.  **Учетные данные администратора по умолчанию:**
    - **Имя пользователя:** `Admin`
    - **Пароль:** `password`
    - *Рекомендуется сменить пароль администратора после первого входа в систему через панель управления пользователями.*

4.  **Удалите установочный файл:**
    - **ВАЖНО:** После успешной установки немедленно удалите файл `install.php` с сервера из соображений безопасности.

## 3. Структура проекта

- `/`: Корневой каталог. Содержит основные страницы (`index.php`, `login.php`, `logout.php`) и файлы конфигурации.
- `/admin/`: Содержит страницы, доступные только администраторам (управление отделами, пользователями, логами).
- `/includes/`: Содержит переиспользуемые файлы PHP, такие как `header.php`, `footer.php` и `functions.php` (например, функция `log_event`).
- `/css/`: Изначально планировался для пользовательских стилей, но в итоге стилизация выполняется через CDN Bootstrap и встроенные теги `<style>`.
- `/js/`: Планировался для скриптов, но используется CDN Bootstrap.

## 4. Основные файлы

- `index.php`: Главная страница. Отображает форму ввода статуса для пользователей отделов и сводную таблицу для всех.
- `login.php`: Страница входа в систему.
- `config.php`: Конфигурация подключения к БД.
- `install.php`: Скрипт для первоначальной установки.
- `admin/departments.php`: CRUD для управления отделами.
- `admin/users.php`: CRUD для управления пользователями.
- `admin/logs.php`: Просмотр и очистка системных логов.
- `includes/functions.php`: Содержит общие функции, в первую очередь `log_event()`.

## 5. Стиль кода и соглашения

- **Бэкенд:** Процедурный PHP с использованием `mysqli` с подготовленными выражениями для предотвращения SQL-инъекций.
- **Фронтенд:** HTML5 с использованием фреймворка **Bootstrap 4**. Все новые визуальные компоненты должны соответствовать стилю Bootstrap для поддержания единообразия интерфейса.
- **Логирование:** Все значимые действия (вход/выход, создание/обновление/удаление сущностей) должны записываться в таблицу `logs` с помощью функции `log_event()`.
