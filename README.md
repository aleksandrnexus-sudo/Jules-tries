Я реализовал многопользовательское веб-приложение на PHP для отслеживания ежедневного статуса сотрудников.

Основные возможности:
- Две роли пользователей: Администратор и Пользователь отдела.
- Панель администратора для управления отделами и пользователями.
- Система логирования всех действий с возможностью просмотра и очистки логов по временным интервалам.
- Панель пользователя для ввода ежедневных данных о количестве сотрудников в различных статусах.
- Сводная таблица с последними данными по всем отделам, доступная всем пользователям.
- Безопасная аутентификация с хешированием паролей.
- Скрипт установки для легкого развертывания.

Требования
Для работы приложения вам понадобится:

Веб-сервер (например, Apache, Nginx).
PHP (версия 7.2 или новее).
Сервер баз данных (MySQL или MariaDB).
Инструкция по развертыванию
Шаг 1: Размещение файлов

Скопируйте все файлы проекта (которые я для вас создал) в папку вашего веб-сервера (например, /var/www/html/ для Apache на Linux или htdocs для XAMPP).
Шаг 2: Настройка базы данных

Создайте новую, пустую базу данных в вашей системе управления базами данных (например, через phpMyAdmin). Назовем ее staff_status.
Создайте пользователя для этой базы данных и предоставьте ему все права доступа.
Откройте файл config.php в корневой папке проекта.
Отредактируйте следующие строки, указав данные для подключения к вашей базе данных:
define('DB_NAME', 'staff_status');      // Имя вашей базы данных
define('DB_USER', 'ваш_пользователь'); // Имя пользователя БД
define('DB_PASSWORD', 'ваш_пароль');    // Пароль пользователя БД
define('DB_HOST', 'localhost');          // Обычно 'localhost'
Шаг 3: Установка приложения

Откройте веб-браузер и перейдите по адресу http://<ваш-сайт>/install.php.
Этот скрипт автоматически создаст все необходимые таблицы в базе данных и добавит пользователя-администратора по умолчанию.
После того как вы увидите сообщение об успешной установке, немедленно удалите файл install.php с сервера. Это очень важно для безопасности.
Инструкция по тестированию
После установки вы можете протестировать основной функционал.

1. Тест под Администратором:

Перейдите на страницу входа: http://<ваш-сайт>/login.php.
Войдите, используя учетные данные по умолчанию:
Имя пользователя: Admin
Пароль: password
Что проверить:
Создание отделов: Перейдите в "Панель администратора" -> "Управление отделами". Создайте 2-3 отдела (например, "Отдел кадров", "Бухгалтерия").
Создание пользователей: Перейдите в "Управление пользователями". Создайте нового пользователя (например, user_hr) с ролью "Пользователь отдела" и привяжите его к одному из созданных отделов.
Просмотр логов: Перейдите в "Просмотр логов". Вы должны увидеть записи о создании отделов и пользователей.
2. Тест под Пользователем отдела:

Нажмите "Выход" в правом верхнем углу, чтобы выйти из учетной записи администратора.
Войдите снова, используя данные пользователя, которого вы только что создали (например, user_hr).
Что проверить:
Ввод данных: На главной странице вам будет доступна форма "Ввод данных за сегодня". Заполните поля (Налицо, Наряд и т.д.) и нажмите "Сохранить данные".
Просмотр таблицы: После сохранения данных, они должны сразу же появиться в сводной таблице ниже.
Ограничение доступа: Убедитесь, что у этого пользователя нет ссылки на "Панель администратора".
3. Финальная проверка (снова под Администратором):

Войдите снова как Admin.
На главной странице вы должны увидеть данные, которые ввел пользователь отдела. Также вы можете проверить итоговую строку "ИТОГО", которая суммирует все значения.
Если все эти шаги работают, значит, приложение развернуто и функционирует правильно.
